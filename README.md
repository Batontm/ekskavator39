# ekskavator39.ru (kopka39)

Резервная копия сайта ekskavator39.ru — WordPress.

Что входит:
- `wp-content/themes/kopka` — тема сайта;
- `wp-content/ekskavator39-assets` — шрифты, иконки, стили;
- `wp-content/mu-plugins` — обязательный плагин;
- `.htaccess`.

Не входит: ядро WordPress, стандартные плагины (Contact Form 7, Akismet), `wp-config.php` с паролями и база данных.

Хостинг: Beget, папка `/ekskavator39.ru/public_html`.
